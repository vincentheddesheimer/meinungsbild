# GESIS Issue Domain Exploration

Last updated: 2026-06-14

Purpose: assess whether the candidate GESIS item list covers "what people think about important political issues" rather than broader political attitudes such as interest, trust, or efficacy.

## Bottom line

The current sendable table has a strong core for immigration, climate, redistribution/social spending, democracy, populism, and economic evaluations. For a stricter "important political issues" framing, the table should add several issue-position domains and demote several attitude/evaluation domains.

The strongest additions are:

1. Ukraine / arms deliveries / defense
2. Bundeswehr or defense spending
3. Nuclear energy / energy transition
4. Housing / rents
5. Bürgergeld, unemployment benefits, or welfare conditionality
6. State spending on health, education, pensions, unemployment support, crime control, and industry
7. Debt brake / wealth tax
8. Direct democracy / federal referenda
9. Selected social/cultural issues: gender equality, same-sex marriage, religious symbols, cannabis
10. Media regulation / civil liberties / freedom-security tradeoffs

The strongest candidates to keep as "core issue opinions" are immigration, climate vs. growth, taxes vs. social spending, income redistribution, social benefits, Ukraine/defense, nuclear/energy, housing/rents, debt brake, and state spending priorities.

The weakest fit for the stated framing are links-right self-placement, political interest, general trust, institution trust, economic situation evaluations, and broad democracy satisfaction. These may be useful context, but they are not issue positions.

## Recommended reclassification of the sendable table

### Core issue-position block

1. Zuwanderung / Asyl / Integration
2. Klimaschutz vs. Wirtschaft / Klimapolitik
3. Kernenergie / Energiewende
4. Umverteilung / Steuern / Sozialleistungen
5. Bürgergeld / ALG II / welfare conditionality
6. Ukraine / Waffenlieferungen
7. Bundeswehr / Verteidigungsausgaben
8. Staatsausgaben: Gesundheit, Bildung, Renten, Arbeitslosenunterstützung, Kriminalitätsbekämpfung
9. Schuldenbremse / Vermögenssteuer
10. Wohnen / Mieten

### Secondary issue-position block

1. Volksentscheid / direkte Demokratie
2. Wahlalter 16
3. Tempolimit
4. Gleichstellung / same-sex marriage / gender roles
5. Medienregulierung / Freiheitsrechte / religiöse Symbole
6. EU / Europa

### Move out of main issue table or label separately

1. Links-Rechts-Selbsteinstufung
2. Demokratiezufriedenheit
3. Allgemeines Vertrauen
4. Institutionenvertrauen
5. Wirtschaftliche Lage Deutschlands
6. Eigene wirtschaftliche Lage
7. Populismus / Anti-Eliten-Einstellungen

These are valuable public-opinion outcomes, but they answer a different question: "how do people orient themselves politically and evaluate institutions?" rather than "what do people think about important political issues?"

## Practical implication for Sebastian

The list should not be framed as "the final harmonization list." It should be framed as:

> a working list of candidate issue-position families, prioritizing items that appear in several regionalized GESIS sources or close source-specific variants.

The first test sample should probably use a small set of clean, repeated issue positions:

1. Zuwanderung einschränken
2. Steuern vs. Sozialleistungen
3. Klimaschutz vs. Wirtschaftswachstum
4. Kernenergie / Atomausstieg
5. Staatsausgaben Bundeswehr or Verteidigungsetat
6. Staatsausgaben Gesundheit/Bildung/Renten/Sozialleistungen

Then expand with newer/current issue items if GESIS confirms the relevant sources are usable:

1. Ukraine arms deliveries
2. Debt brake
3. Housing/rent regulation
4. Bürgergeld cut / ALG-II conditionality
5. Speed limit
6. Gender equality / same-sex marriage
